
# 🌀 Spiral Art Generator with Turtle

This interactive project uses Python’s built-in `turtle` graphics module to generate evolving spiral patterns based on angle, pen size, and color settings. It’s a creative coding experience designed to help you practice Python in a visual and playful way.

## 🚀 What You'll Learn

By working through this project, you’ll explore:

- How to animate shapes using loops
- Using turtle commands to control drawing speed, position, and angle
- Creating interactive inputs using sliders and buttons
- Structuring code to support user input and dynamic visuals
- Customizing colors, pen sizes, and turtle behavior in real time

This is a great way to bridge the gap between basic syntax and visual programming while reinforcing logic and function structure.

## 📦 Requirements

- Python 3.x
- `turtle` and `tkinter` modules (included with standard Python)
- Jupyter Notebook (or compatible editor)

## 🧠 Prerequisites

- Familiarity with loops, variables, and functions in Python
- No prior turtle experience required — the notebook walks you through it
- A creative mind ready to experiment!

## 💡 How to Use

1. Open `Spiral.ipynb` in Jupyter Notebook.
2. Run all cells to launch the GUI.
3. Adjust parameters like:
   - Pen size
   - Rotation angle
   - Color
4. Press the “Preview” button to render the spiral instantly.

Experiment with patterns and see how math and art collide!
