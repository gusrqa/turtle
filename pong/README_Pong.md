
# 🏓 Pong Game with Turtle

This interactive Pong game is built using Python's built-in `turtle` graphics module. It provides a fun and engaging way to practice Python programming while learning fundamental concepts used in 2D game development.

## 🚀 What You'll Learn

By working through this notebook, you will:

- Understand how to use the `turtle` module to draw and animate shapes
- Learn to create a game loop using `while` and screen update mechanics
- Handle keyboard input for player control
- Manage collision detection logic for ball and paddle interactions
- Use functions and object-oriented thinking to structure a game
- Track and display a scoring system
- Practice debugging and extending a simple Python-based game

This project is well-commented and beginner-friendly, making it perfect for learners who want to transition into **intermediate Python projects** through real examples.

## 📦 Requirements

- Python 3.x installed on your system  
- `turtle` module (included by default with Python)
- Jupyter Notebook (optional but recommended for the `.ipynb` file)

## 🧠 Prerequisites

- Basic knowledge of Python syntax (functions, loops, conditionals)
- Familiarity with variables and control flow
- Some experience with Jupyter Notebooks or running Python scripts

## 💻 How to Run the Game

1. Open the `Pong.ipynb` notebook using Jupyter Notebook or JupyterLab.
2. Run the cells one by one to launch the game window.
3. Use the `W`/`S` keys for Player A and `Up`/`Down` arrow keys for Player B.
4. Enjoy the game and explore the code to understand how it all works!
