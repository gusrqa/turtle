
# 🐍 Snake Game with Turtle

This interactive Snake game is built using Python’s `turtle` graphics module and is designed to help you learn Python through a fun, hands-on project. The game recreates the classic Snake experience where the player maneuvers the snake to eat food, grow longer, and avoid crashing into itself.

## 🚀 What You'll Learn

By working through this notebook, you will:

- Use the `turtle` module to draw shapes and handle animation
- Implement a game loop using `while` and screen updates
- Capture keyboard input for real-time direction changes
- Handle collision detection between the snake and walls or itself
- Manage game state and logic for restarting and scoring
- Build confidence structuring more complex Python programs

This notebook is well-documented and beginner-friendly, making it ideal for learners transitioning into **intermediate-level programming**.

## 📦 Requirements

- Python 3.x
- `turtle` module (standard in Python)
- Jupyter Notebook (recommended for this `.ipynb` version)

## 🧠 Prerequisites

- Basic Python knowledge: loops, conditionals, variables, and functions
- Comfort running notebooks or Python scripts
- Curiosity and willingness to experiment with code!

## 💻 How to Play

1. Open the `Snake.ipynb` notebook in Jupyter.
2. Run all cells to launch the game.
3. Use the arrow keys to move the snake around.
4. Eat food to grow longer. Avoid hitting the walls or your own tail!
