
# ❄️ Fractal Snowflake Generator (with Turtle & Tkinter)

This interactive project uses Python’s built-in `turtle` module in combination with `tkinter` to generate beautiful, customizable fractal snowflakes. It’s a visually creative way to learn recursion, geometry, and basic GUI development.

## 🚀 What You'll Learn

By using this notebook, you’ll get hands-on practice with:

- Recursion: how functions can call themselves to create repeating patterns
- Geometry: angles, rotation, and scaling in visual patterns
- Turtle graphics: drawing complex shapes using basic instructions
- Tkinter: adding sliders and dropdowns to make dynamic controls
- Code organization: separating logic from interface for clarity

This project is perfect for learners who want to explore how Python can be used not just for calculations or data—but to make interactive art.

## 📦 Requirements

- Python 3.x
- `turtle` and `tkinter` (both included in standard Python)
- Jupyter Notebook or Python script runner

## 🧠 Prerequisites

- Comfortable with basic Python (loops, functions, and variables)
- No prior experience with GUIs required — everything is explained
- Willing to experiment with angles, sliders, and recursion depth

## 🖱️ How to Use

1. Open `Snowflake.ipynb` in Jupyter Notebook.
2. Run all the cells to launch the control panel.
3. Use sliders to change:
   - Number of arms
   - Depth of recursion
   - Snowflake color
4. Click “Preview” to draw the snowflake in real time!
